# E-Commerce Sales Dashboard (Power BI)

## Overview

This project presents an interactive Power BI dashboard analyzing e-commerce sales data to track business performance and key trends.

## Key Metrics

* Total Revenue: £8.9M
* Total Orders: 26K
* Total Customers: 4K
* Average Order Value: £343

## Features

* Monthly revenue trend analysis
* Top-performing products
* Revenue distribution by country
* Interactive filters (date range, country)

## Tools Used

* Power BI
* Power Query
* DAX
